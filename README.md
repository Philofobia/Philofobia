<h3>👋 Hey, I'm a full-stack web developer</h3>

<p>
  I spend most of my time in the <strong>JavaScript / TypeScript</strong> world, building the kind of
  front-ends that have to look great <em>and</em> survive a lot of traffic. Over the last few years I've
  shipped production apps with consulting teams for international <strong>luxury fashion</strong> and
  <strong>e-commerce</strong> brands — everything from new storefront sections and shared component
  libraries to the unglamorous-but-important stuff that keeps a site fast.
</p>

<p>
  I like the whole stack: a clean, well-typed React UI on one end, a sensible API and a few well-behaved
  microservices on the other.
</p>

<h3>🛠️ What I actually do</h3>

<ul>
  <li><strong>Front-end at scale</strong> — storefronts, product listing/detail pages, reusable component libraries, and A/B-tested features for sites that get real traffic.</li>
  <li><strong>Performance obsessing</strong> — prefetching, prerendering, the Speculation Rules API, analytics tracking — shaving load times until pages feel instant.</li>
  <li><strong>APIs &amp; back-end</strong> — REST and GraphQL endpoints, plus SOLID-minded microservices (carts, sales, dynamic discounting) wired up to external services and watched over with proper monitoring.</li>
  <li><strong>End-to-end products</strong> — a ticketing portal with secure payments, a civic platform for a regional capital, and a micro-frontend reporting tool with in-app chat.</li>
  <li><strong>Teaching, occasionally</strong> — workshops on building a platformer game and a Python/Ren'Py visual novel, because explaining things makes you better at them.</li>
</ul>
